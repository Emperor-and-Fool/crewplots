# MongoDB Utilities

Development utilities for MongoDB operations and testing.

## Files

### delete-mongo-doc.js
Quick script to delete specific MongoDB documents via API calls.

Usage:
```bash
node delete-mongo-doc.js
```

Note: Update document IDs and authentication cookies as needed for your environment.

### mongo-proxy-server.js
MongoDB proxy server for development environments. Provides MongoDB connectivity and proxy functionality for local development.

Usage:
```bash
node mongo-proxy-server.js
```

## Purpose

These utilities support MongoDB development, testing, and maintenance operations in the CrewPlots project.
